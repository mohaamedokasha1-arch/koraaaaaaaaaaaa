| الدوري | TheSportsDB league id | api-football id (اختياري) | التحقق الفعلي |

## 3) الفجوات الحقيقية المتبقية مقابل الـ"Master Prompt" (بعد التصحيح)

هذه هي الفجوات الصادقة الوحيدة التي تستحق عملاً فعلياً الآن، مرتّبة:

1. **تفعيل الأخبار** — البنية الكاملة جاهزة (News Hub + تصنيف + إزالة تكرار + ربط كيانات)، لكن
   `NEWS_FEEDS`/`NEWS_PRESETS` فارغان بشكل متعمَّد لأن تفعيل مصدر إخباري قرار **قانوني/تجاري** وليس تقني
   (BBC Sport RSS مثلاً يشترط إسناداً ظاهراً وموافقة للاستخدام التجاري). المصادر المُتحقَّقة والجاهزة
   للتفعيل الفوري بمجرد موافقتك: `youm7-sport` (عربي، مصري أولاً)، `kingfut` (إنجليزي، مصر)،
   `bbc-sport-football`، `guardian-football` — القائمة الكاملة بأسمائها وشروطها في
   `src/lib/newsSources.ts` و`docs/PLATFORM-V2.md` §2.
2. **توسعة البطولات الدولية بقالب صفحة بطولة كأس** (كأس العالم، أمم أفريقيا، كأس آسيا، أبطال آسيا،
   أبطال أفريقيا) — تحتاج قالب جديد (لا جدول ترتيب تقليدي، بل أدوار/مجموعات) فوق مصدر ESPN المُتحقَّق أعلاه.
3. **صفحات لاعبين كاملة (Player Hub)** — ممكنة فقط من التشكيلات الموثوقة الحالية (لا بحث لاعب عالمي، لأسباب
   موثّقة في §2.2)، أي: صفحة لكل لاعب تُبنى من بيانات التشكيلة الحقيقية المرتبطة بفريقه الحالي + سجل
   الهدافين، لا من قاعدة بيانات لاعبين عالمية غير موثوقة.
4. **التحويلات (Transfers)** — لا يزال لا يوجد مصدر مجاني فعلي وقانوني متحقَّق يقدّم بيانات تحويلات منظَّمة
   (نفس خلاصة `SOURCE-EVALUATION.md`). البديل الصادق الوحيد: تصنيف الأخبار التي تصل عبر News Hub كـ"نوع:
   تحويل" (الكود يفعل هذا فعلاً في `newsIntel.ts`) بدل جدول تحويلات مُختلَق.
5. **الإحصائيات/التشكيلات التفصيلية داخل المباراة (Lineups/Stats tabs)** — ما زالت خلف خطط مدفوعة في كل
   مزوّد مجاني مُتاح؛ تظهر فقط عندما يُرجعها مزوّد فعلاً (لا اختراع لأرقام).
