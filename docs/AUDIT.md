## 5. حالة SEO قبل التعديل (الأخطاء المرصودة بالفحص الفعلي)

| # | الخطأ | الدليل |
|---|---|---|
| 1 | **Canonical عام على كل الصفحات** | `GET /ar/live` → `<link rel="canonical" href=".../ar"/>` (موروث من الـlayout) — أخطر خطأ: يخبر Google أن كل الصفحات هي الرئيسية |
| 2 | **`robots.txt` يحجب `/_next/`** | يحتوي `Disallow: /_next/` = منع JS/CSS اللازمة للعرض |
| 3 | **لا hreflang ولا x-default** | لا توجد وسوم `alternate` في HTML إطلاقاً |
| 4 | **Sitemap بـ`lastModified: new Date()` لكل رابط** | توقيت غير صادق يتغيّر كل طلب |
| 5 | **صفحات 404 تحمل Canonical للرئيسية** | `/ar/teams/bad` → canonical `.../ar` مع 404 |
| 6 | **تبويبات `?tab=` بدون Canonical موحّد** | نسخ مكرّرة قابلة للفهرسة |
| 7 | **عناوين/أوصاف عامة مكرّرة** | معظم الصفحات تستخدم نفس `dict.site.description` |
| 8 | **لا حماية للمعاينة (Preview)** | لا `X-Robots-Tag` ولا فصل بيئة |
| 9 | **Structured Data ناقص** | SportsEvent فقط، بلا BreadcrumbList/WebSite/Organization |
| 10 | **صفحة بحث داخلية عبر `/api/search`** | لا صفحة HTML للبحث (لا خطر فهرسة، لكنها فجوة UX/SEO) |

## 7. Vercel

- البناء: `next build` (لا خطوة build مخصصة)، Output افتراضي، تكامل GitHub → Vercel مباشر.
- Runtime: Node للـRoute Handlers والصفحات الديناميكية (لا Edge).
- Cron: `/api/cron/warm` يومياً `0 6 * * *` (متوافق مع Hobby) ومحمي بـ`CRON_SECRET`.
- Cache: في الذاكرة لكل نسخة (مُوثّق كطبقة تحسين لا يعتمد عليه الصواب) + نافذة Stale 24h.
- لا كتابة على نظام الملفات، ولا حالة دائمة بين الطلبات. ✅

## 8. الديون التقنية والمخاطر

1. الـCache في الذاكرة لا يُشارك بين النسخ/المناطق → احتمال نداءات مزوّد مكرّرة عند التوسّع (الحل المستقبلي: Redis/KV — الاستبدال محصور في `cache.ts`).
2. غياب الاختبارات يجعل أي تعديل على المحلّلات (parsers) غير محمي → أُضيفت اختبارات هذه الجولة.
3. الدوري المصري معتمد على مزوّد واحد عملياً + سقوف الخطة المجانية.
4. لا معالجة إساءة استخدام لمنافذ `/api/*` (يمكن استنزاف حصة المزوّدين) → أُضيف Rate limiting هذه الجولة.
5. صفحات بطاقات `?tab=` تُولَّد ديناميكياً في كل طلب (لا مشكلة أداء حقيقية الآن بسبب الـCache).

**الخلاصة:** ما يعمل جيداً (نظام المزوّدين المتعدّد، الـCache المتدرّج، الـFallback، التصميم، RTL، الـRoutes) **بقي كما هو**، والتعديلات تركّزت على: مصادر بيانات جديدة، إصلاحات فهرسة حرجة، وطبقات جودة/أمان إضافية.
