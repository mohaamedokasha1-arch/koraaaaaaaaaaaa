### 1.2 نظام الأخبار الحالي

- **موجود وليس "غير موجود"** (على عكس `AUDIT.md` القديم): `src/lib/news.ts` + `providers/rssNews.ts` + `pure/rss.ts` + `components/news-list.tsx` + `/[locale]/news` + شريط في الرئيسية + رابط "الأخبار" في الـnav.
- **Opt-in بالكامل:** لا يُجلب شيء إلا إذا وُضع `NEWS_FEEDS` (`الاسم|URL` مفصولة بفواصل). بدونه: حالة فارغة + `noindex` + لا طلبات خارجية. **لا أعرف إن كان معيّنًا في Vercel الآن.**
- **الجلب:** عند طلب المستخدم (`getNews`) مع كاش ذاكرة 600ث؛ `Promise.allSettled` عبر القنوات، Circuit breaker لكل قناة، سقوط إلى آخر كاش (stale) عند فشل الجميع.
- **ما يُخزَّن:** `{id,title,url,source,sourceUrl,publishedAt,excerpt≤220}` — عنوان/مقتطف/وقت/مصدر/رابط فقط ✅ (لا نص كامل، لا ترجمة).
- **ما ينقص:** لا صورة، لا لغة، لا تصنيف، لا ربط بكيانات، لا Clusters، لا Pagination، لا فلاتر، وإزالة التكرار بدائية (URL + أول 90 حرفًا من العنوان بحروف صغيرة؛ بلا تطبيع عربي ولا زمن).

### 1.4 البحث
`/api/search?q=` → `football.search()`: تطبيع عربي جيد (`normalizeText`: همزات، ة/ه، ى/ي، تشكيل، أرقام هندية) + توسيع بالـaliases + استدعاء `searchTeams` **لـ TheSportsDB فقط** + مطابقة البطولات من القائمة الثابتة. Rate limit 40/د، Cache 30د.
**لا يبحث** في: اللاعبين، الأخبار، المباريات. لا تجميع حسب النوع، لا معالجة غموض (الأهلي المصري/السعودي) مع الدولة. الواجهة: Debounce + حد أدنى حرفين ✅.

### 1.5 Caching / Revalidation / Cron
- `cache.ts`: Map داخل الذاكرة لكل نسخة Serverless، TTL متدرّج (25ث مباشر … 24س فرق)، نافذة stale 24س، حد 2000 مدخل مع إخلاء. **لا يُشارك بين النسخ ولا يصمد بعد cold start.**
- لا `fetch` مع `revalidate`/ISR: كل الصفحات `force-dynamic`؛ الكاش طبقة ذاكرة فقط.
- `vercel.json`: Cron واحد يومي `0 6 * * *` → `/api/cron/warm` (يُسخّن المباشر/اليوم/أمس/غدًا فقط، ولا يلمس الأخبار) محمي بـ `CRON_SECRET`. هذا متوافق مع Hobby.
- Request dedup: `React.cache` لبعض القراءات (`getTeamMemo`)، وتجميع طلبات مشتركة في `cachedCall`.

### 1.9 ديون وأخطاء تؤثر على الإضافات (مؤكدة بالتجربة)

1. **🔴 ثغرة في `safeLink` (`src/lib/pure/rss.ts`)**: الجذر يُحسب بآخر مقطعين من نطاق الـfeed ثم `endsWith` بلا حد نقطة. جرّبت فعليًا: feed على `feeds.bbci.co.uk` **يقبل أي رابط `*.co.uk`** (مثل `evil.co.uk`)، وfeed على `rss.example.com` يقبل `evilexample.com`. BBC يعمل *بالصدفة* (لأن الجذر = `co.uk`). يجب إصلاحه بقائمة نطاقات مسموحة صريحة لكل مصدر. (مرفوض: الاعتماد على الحالي لمصادر جديدة.)
2. **لا ذاكرة دائمة**: لا أخبار/كيانات/سجلات صحة تصمد بين النسخ. أي "Cluster" أو "سجل صحة" سيكون لكل نسخة على حدة ما لم يُقرَّر تخزين (انظر القرارات).
3. **الجلب أثناء طلب المستخدم** (`getNews` داخل الصفحة عند انتهاء الكاش) — يخالف شرط "الجلب في الخلفية أو عبر الكاش لا أثناء الطلب" عند توسّع المصادر.
4. **المعرّفات مرتبطة بالمزوّد** → لا slug ولا دمج كيانات.
5. **`constants.ts` قائمة بطولات مغلقة.**
6. **صورة الخبر غير مدعومة** و`next.config.mjs` `remotePatterns` لا يحتوي نطاقات صور الأخبار.
7. **`User-Agent` يشير لنطاق `korascore.app`** (قد لا يكون نطاقكم الفعلي) — يُراجع.
8. لا CSP (رؤوس أمان أخرى موجودة).
