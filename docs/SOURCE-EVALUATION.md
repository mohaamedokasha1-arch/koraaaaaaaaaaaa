# المرحلة 2 — Source Evaluation Report

> كل مصدر هنا **فُحص فعلياً** (طلب حقيقي أو توثيق رسمي مقروء) في تاريخ 2026-09-30.
> ما لم أستطع التحقق منه مذكور كـ"مرشح غير مؤكد" **ولم يُدمَج في الكود**.

## قيود بيئة التحقق

- الـshell في بيئة العمل هذه **لا يملك شبكة صادرة** (DNS يعمل، الاتصال محجوب)، لذلك تم التحقق من المصادر عبر أداة الجلب/التصفح (طلبات HTTPS فعلية) وليس عبر تشغيل التطبيق محلياً.
- لا وصول إلى مفاتيح المزوّدين، ولا إلى Vercel، ولا إلى Search Console.

## 2. المصادر المقبولة والمُدمَجة

### 2.1 openfootball — `football.json` + `world` (بيانات تاريخية) ✅ مُدمَج

| البند | النتيجة |
|---|---|
| يعمل الآن؟ | ✅ `raw.githubusercontent.com/openfootball/football.json/master/2025-26/en.1.json` — بيانات موسم 2025/26 كاملة (آخر تحديث للملف 24 أغسطس 2026) |
| يعمل لمصر؟ | ✅ `world/master/africa/egypt/2024-25_eg1.txt` — **225 مباراة، 18 فريقاً**، نتائج كاملة + نتيجة الشوط الأول |
| المفتاح والحدود | بلا مفتاح، بلا Rate limit موثّق؛ ملفات ثابتة (35–100 KB للملف) تُخزَّن 24 ساعة |
| الترخيص | **CC0-1.0 / ملكية عامة** — نص رسمي في README المستودع: *"The football.db schema, data and scripts are dedicated to the public domain. Use as you please with no restrictions whatsoever."* |
| العرض العام | مسموح بلا قيود، ومع ذلك يُعرض الإسناد في الواجهة (ممارسة جيدة) |
| التغطية | مواسم مكتملة منذ 2010/11 لـ: إنجلترا (1–4)، إسبانيا (1–2)، إيطاليا (1–2)، ألمانيا (1–2)، فرنسا (1–2)، هولندا، البرتغال، النمسا (1–2)، بلجيكا، اليونان، إسكتلندا، تركيا + **الدوري المصري (2023-24 و2024-25)** |
| الفجوة التي يسدّها | **Historical Data** (لم يكن موجوداً إطلاقاً) + تاريخ الدوري المصري الذي لا يوفّره أي مزوّد حيّ حالياً |
| خطة الدمج | مُحوِّل مستقل `src/lib/providers/openfootball.ts` + خدمة `src/lib/historical.ts` + تبويب "مواسم سابقة" في صفحة البطولة. **لا يشارك في سلسلة البيانات الحيّة إطلاقاً** فلا يمكن أن يخفض جودة أو يبطئ مصدراً يعمل |
| التوقعات الصادقة | البيانات تاريخية فقط (لا مباشر)، ولا شعارات فرق (تُعرض الأسماء فقط)، والأسماء كما كتبها المصدر |

استنتاجات التحقق من المحتوى الفعلي:
- بنية `football.json`: `{name, matches:[{round,date,time,team1,team2,score:{ft:[..],ht:[..]}}]}` — تم التحقق من أن حقل `score` يظهر أحياناً كمصفوفة `[0,0]` بلا شوط أول ⇒ التعامل مع الحالتين، ولا اختراع لقيم ناقصة.
- بنية `world` بصيغة Football.TXT: `▪ Matchday N` / `  Wed Oct 30 2024` / `    17:00  Home v Away 1-3 (1-2)` — تم التحقق من أن بعض سطور التاريخ تحذف السنة (تُستنتج من الموسم) ومن ضرورة تحويل التوقيت من توقيت القاهرة (مع مراعاة التوقيت الصيفي المصري المُعاد العمل به منذ 2023).

### 2.2 RSS الأخبار الرياضية (نوع المصدر: News / Football RSS) — مُدمَج كـ**اختياري Opt-in**

| البند | النتيجة |
|---|---|
| يعمل الآن؟ | ✅ تم جلب `https://feeds.bbci.co.uk/sport/football/rss.xml` بنجاح — 30+ عنواناً بتاريخ 30 سبتمبر 2026 |
| المفتاح | لا يحتاج مفتاحاً |
| الشروط الرسمية | صفحة BBC Sport الخاصة بـRSS: *"we require that the proper format and attribution is used … The attribution text should read \"BBC Sport\" … You may not use any BBC logo"*، كما أن شروط الاستخدام تسمح بالاستخدام على مواقع الأفراد وتطلب موافقة BBC للاستخدام التجاري |
| قرار المشروع | ✅ البنية مُبنية، ❌ **غير مُفعّلة افتراضياً**. التفعيل بقرار المشغّل عبر `NEWS_FEEDS` (هو من يقرّر الترخيص التجاري لكل مصدر). بدون المتغيّر: لا يُجرى أي طلب خارجي، وصفحة `/news` تُخرج `noindex` تلقائياً |
| ما نعرضه | العنوان + مقتطف ≤220 حرفاً + وقت النشر + اسم المصدر + رابط الخبر الأصلي فقط — **لا نعيد نشر المقال كاملاً** |
| الحماية المطبقة | إزالة الوسوم/السكربتات، فك الكيانات، تقييد الروابط بموقع المصدر نفسه (منع روابط خارجية مُدسّة)، رفض التواريخ غير المنطقية، تنظيف معاملات التتبع، ومنع التكرار |
| خطة الدمج | `src/lib/providers/rssNews.ts` (شبكة) + `src/lib/pure/rss.ts` (محلّل مُختبَر) + `src/lib/news.ts` (خدمة + Health لكل قناة) + صفحة `/news` + شريط على الرئيسية عند التفعيل |

## 5. متغيرات البيئة الجديدة (أسماء فقط)

| المتغير | الغرض | مطلوب؟ |
|---|---|---|
| `OPENFOOTBALL_ENABLED` | تفعيل/تعطيل مجموعة البيانات المفتوحة | اختياري (افتراضي `true`) |
| `OPENFOOTBALL_TIMEOUT_MS` | مهلة تحميل الملفات التاريخية | اختياري |
| `NEWS_FEEDS` | قائمة قنوات RSS بصيغة `Label\|URL` — **غيابها = تعطيل كامل** | اختياري (قرار المشغّل) |
| `NEWS_TIMEOUT_MS` | مهلة جلب القنوات | اختياري |
| `PROVIDER_TEXT_TIMEOUT_MS` · `PROVIDER_MAX_TEXT_BYTES` | حماية تنزيلات النصوص/XML | اختياري |

كما أُضيف ملف `.env.example` (كان مذكوراً في README وغير موجود) يوثّق كل المتغيرات بأسمائها دون قيمها.
